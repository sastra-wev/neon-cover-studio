# Neon Cover Studio

A GTA-style cover art maker: drop in your own photo, arrange it across a
multi-panel poster layout, grade it with a Vice City sunset or neon look,
add bold caption lettering and export a share-ready PNG
(1080x1080, 1080x1350 or 1920x1080). Static web app, no build step,
no network — your photos never leave your machine. Original design;
no Rockstar artwork, logos or fonts.
